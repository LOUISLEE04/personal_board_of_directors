# Outreach Tracker

> Tracks all emails, DMs, and contact attempts for social, career, and community outreach.
> Update whenever: a new contact is made, a reply is received, or a follow-up is done.
> Agents read this before every session — closed/on-hold entries are never re-recommended.

---

## Legend

| Status | Meaning |
|--------|---------|
| `recommended` | Research suggested this outreach — NOT yet confirmed sent |
| `sent` | Confirmed sent, no reply yet |
| `replied` | Got a response (see notes) |
| `follow-up-pending` | Need to send a follow-up |
| `in-progress` | Actively engaged, ongoing relationship |
| `closed` | No longer pursuing — agents will NOT recommend this again |
| `on-hold` | Paused for now |
